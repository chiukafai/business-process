企业微信通知（自建应用）
开通后，业务提交 / 被退回 / 付款完成会自动推送到对应人员的企业微信
关闭时系统只在站内待办里提示，不发任何外部请求
保存后仅用于服务端取 token，不会出现在任何页面和日志里
接入前必须确认两件事（否则会报 60020 或 48002）
1. 企业微信后台 → 应用管理 → 你建的自建应用 → 「企业可信IP」里，必须填本系统所在服务器的公网出口 IP。
2. 该应用的可见范围要包含需要收通知的成员，否则他们收不到消息。
3. 当前系统跑在本机，家宽/办公网出口 IP 会变，只有部署到固定 IP 的服务器（或固定出口的云主机）后才能稳定推送。
